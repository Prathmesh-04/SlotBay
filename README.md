# SlotBay

A two-sided parking marketplace for iOS. Drivers find and book a spot; hosts list the space they don't use.

Built with SwiftUI.

## Status

Early development. See the roadmap below.

## Roadmap

- [ ] Project skeleton
- [ ] Accounts and roles (driver / host)
- [ ] Host listings and slots
- [ ] Map search and filters
- [ ] Pricing and booking
- [ ] Payments
- [ ] Access pass (QR and PIN) and gate check-in
- [ ] Host dashboard and payouts
- [ ] Notifications, reviews, receipts
- [ ] Admin tools and polish

## Requirements

- Xcode 27 or later
- iOS 18 or later
